# Using the converter

Type a value, pick a source and target unit, and the result updates as you type. The swap button exchanges the units. Mismatched units or a non-number show an error under the form. The address bar keeps `?value=…&from=…&to=…`, so a link reproduces the conversion; unit names in links must be canonical symbols such as `km`.

The page, and the Chrome popup, reopen on the units you used last. A link that names units (`?from=…` or `?to=…`) always wins over that memory.
